# 개발 모드와 바탕화면 바로가기

Windows에서 프로젝트 루트의 [Create Bitwiser DEV Shortcut.vbs](../Create%20Bitwiser%20DEV%20Shortcut.vbs)를 더블클릭하면 바탕화면에 **Bitwiser DEV** 바로가기가 생깁니다. 이후에는 바로가기를 더블클릭하면 됩니다. Electron 실행 파일을 직접 사용하므로 검은 터미널 창이 열리지 않습니다. 최초 의존성 설치(`npm ci`)는 필요하며, 설치가 없으면 생성기가 안내합니다.

바로가기는 현재 프로젝트 소스를 실행합니다. 코드를 수정한 뒤 앱을 완전히 종료하고 다시 열면 반영됩니다. 이미 실행 중이면 기존 DEV 창이 앞으로 나옵니다. 프로젝트를 옮겼다면 생성 파일을 다시 실행하세요. 같은 이름의 DEV 바로가기를 갱신합니다.

| 실행 | 동작 |
| --- | --- |
| `npm start` | 기존 일반 실행 |
| 바탕화면 Bitwiser DEV 또는 `npm run dev` | 별도 Electron 프로필의 개발 실행 |
| `npm run dev:web` | `http://127.0.0.1:8731`의 웹 개발 실행 |

웹은 이 DEV 전용 주소/포트를 계속 사용해야 상태가 유지됩니다. 정식판/체험판 서버로 해당 포트를 공유하지 마세요. `DEV_PORT`로 바꾸면 다른 origin이 되어 저장 공간도 달라집니다. 일반 페이지에 `?dev`를 붙이는 방식으로는 개발 모드가 켜지지 않습니다.

## 진행 상태 패널

오른쪽 아래 **DEV** 또는 **Ctrl+Shift+D**로 열고 닫습니다. Escape로 닫을 수 있습니다. 패널의 변경은 맵·진행 수·별과 이후 문제 진입 검사에 즉시 반영됩니다. 진행만 바꾸므로 현재 편집 중인 회로를 교체하지 않습니다.

| 기능 | 의미 |
| --- | --- |
| Chapter 기본 규칙 | 실제 해금 조건과 이미 획득한 접근권 적용 |
| 강제 잠금 / 강제 해금 | 클리어·접근권 보존보다 우선하는 테스트용 설정 |
| 전체 해금 | 모든 Chapter를 강제 해금. 클리어·별은 유지 |
| 기본 규칙으로 | 모든 강제 접근 설정 제거 |
| 스테이지 진행 | 미클리어 또는 클리어 + 별 1/2/3. 튜토리얼은 별 없음 |
| 처음 시작 | 진행·최고 기록·강제 설정을 지운 새 진행 |
| Ch.2 해금 직전 | Ch.1에서 XOR(6)만 미클리어. XOR를 실제 채점 통과하면 Ch.2 해금 |
| Ch.3·4 해금 직전 | Ch.1·2에서 자동문(30)만 미클리어. 자동문을 실제 채점 통과하면 Ch.3·4 해금 |
| 전체 클리어 | 전체 클리어 + 별 3개, 튜토리얼은 별 없음 |
| 테스트 초기화 | **이번 앱/페이지 실행 시 읽은 진행 상태**로 복원. 빈 상태는 ‘처음 시작’ 프리셋 사용 |

프리셋은 진행·별·비용 기록·강제 설정 전체를 교체합니다. 수동으로 클리어/별을 바꾼 문제의 검증된 비용 기록은 제거하며, 가짜 회로/랭킹 기록은 만들지 않습니다. 실제 채점을 통과하면 기존 채점·비용 버전 규칙으로 DEV 기록을 생성합니다. 실패/취소는 클리어를 만들지 않습니다.

일반 규칙에서는 한 번 획득한 접근권을 보존합니다. 특정 문제를 미클리어로 바꾸는 것만으로 Chapter가 다시 잠기지는 않습니다. 반복 테스트에는 강제 잠금 또는 프리셋을 사용하세요.

## 저장과 배포 경계

- Electron 개발 프로필: `%APPDATA%/Bitwiser-DEV`. 일반 프로필과 별도의 Chromium 저장 공간과 회로 저장 폴더를 사용합니다. single-instance lock도 프로필 지정 이후 획득하므로 일반판과 DEV를 동시에 사용할 수 있습니다.
- 진행 키: `bitwiser:dev-progress:v1`. 웹은 DEV 전용 origin에 저장하며, 일반 비용/접근권 키를 진행 공급원으로 사용하지 않습니다. 종료·재실행해도 유지됩니다.
- 초기화와 프리셋은 DEV 진행 기록만 바꾸며, 별도로 저장한 회로 파일·설정·힌트는 지우지 않습니다. 저장 실패는 패널에 ‘현재 실행에서만 유지’로 표시합니다. 손상된 진행 원문은 다음 저장 시 `:recovery` 키에 보존합니다.
- DEV HTML은 실행 시 정식 HTML에서 구성하며 Firebase/광고 SDK와 서비스 워커를 제외합니다. `db`/`firestore`는 연결하지 않습니다. CSP와 Electron 세션의 외부 네트워크 차단으로 실제 랭킹에 제출되지 않습니다. 계정·온라인 데이터가 필요한 기능은 DEV에서 오프라인 상태입니다.
- 배포용 Electron 파일 목록은 `src/dev/`, `electron/dev/`를 제외합니다. 개발 서버·바로가기 생성기도 배포 목록에 없습니다. 체험판 빌드는 DEV 진입점을 참조하지 않습니다. 일반 `index.html`은 DEV 코드를 로드하지 않습니다.

검증: `npm test`, `npm run test:dev:browser`, `npm run test:dev:electron`. 브라우저 검사는 한영 패널 조작, 실제 관문 채점, 맵과 진입 판정 일치, 저장·초기화를 검사합니다. Electron 검사는 임시 테스트 프로필에서 실제 DEV 진입점과 재실행 복원·native IPC·네트워크 차단을 확인합니다. 기존 회귀 명령은 [개발 흐름](development-workflow.md)을 참고하세요.
