최종 채택한 평면 해답 20개

모든 수치는 표시된 평면 회로의 실제 블록 수입니다. INPUT·OUTPUT도 포함하며 각 블록 비용은 1입니다. 원본과 규칙을 바꾼 버전을 구분해서 확인할 수 있습니다.

문제 / 버전평면 총수내부검증 전이 / tick

기본 블록: AND·OR·NOT·D·D+EN. 메모리 초기값 0, 동시 갱신 후 출력 관찰. 회로의 전체 연결 그래프를 검사하며 고정 단자 위치·포트 방향·격자 배치는 포함하지 않습니다.

문제 규칙과 입출력

동작 규칙

    입출력

    주황 점선: D 입력파랑 점선: EN 입력블록에 D / D+EN 종류를 명시했습니다.
    위상 배치의 정점 번호
    정확한 연결식 · JSON

    DE(DATA, EN)는 EN=1일 때 DATA를 저장하며, EN=0일 때 이전 값을 유지합니다. 모든 메모리의 우변은 갱신 전 상태로 계산합니다.

    

    한 tick씩 실행
    아래 값은 해당 tick의 입력입니다. 선택한 값은 다음 tick에도 유지됩니다. ‘새 실행’은 테스트를 처음부터 시작하며 회로에 RESET 입력을 추가하지 않습니다.
