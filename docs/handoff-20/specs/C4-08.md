# 8. 공평한 사용권

**선택한 판:** `C4-08` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `REQ_A` | A의 자원 요청(스위치) |
| 입력 | `REQ_B` | B의 자원 요청(스위치) |
| 출력 | `A_OK` | 이번 tick의 A 승인 |
| 출력 | `B_OK` | 이번 tick의 B 승인 |

**초기 상태:** A_OK=B_OK=0. 승인 이력은 없으며, 최초 동시 요청은 A 우선이다.

**동작 규칙**

- REQ_A=REQ_B=0이면 A_OK=B_OK=0이며 승인 이력은 유지한다.
- 한쪽만 요청하면 그쪽만 승인한다.
- 둘 다 요청하면 마지막으로 승인받은 장치의 반대쪽을 승인한다.
- 아직 승인 이력이 없다면 동시 요청에서 A를 승인한다.
- 단독 요청에 대한 승인도 마지막 승인 이력을 갱신한다.
- A_OK·B_OK는 이번 tick에 승인받은 장치를 나타내며 동시에 둘 다 1이 될 수 없다.

**예시:** 둘 다 계속 요청하면 A,B,A,B,… 순서로 승인한다. A만 승인받은 뒤 요청 없는 tick을 거쳐 둘 다 요청하면 B가 승인된다.
