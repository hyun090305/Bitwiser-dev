# 12. 주소로 저장하고 읽기

**선택한 판:** `C5-02-core` · RESET만 제거. 원본의 나머지 입력·출력·핵심 동작 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `D0,D1` | 기록할 값 |
| 입력 | `ADDR` | 읽기·쓰기 주소 0/1 |
| 입력 | `WRITE` | 쓰기 요청 |
| 출력 | `Q0,Q1` | 현재 주소의 2-bit 값 |

**초기 상태:** 주소 0과 주소 1의 저장값이 모두 00.

**동작 규칙**

- 각각 2비트를 저장하는 공간 두 개를 두고 ADDR=0 또는 1로 선택한다.
- WRITE=1인 tick에만 선택된 공간에 D1D0을 저장한다. 선택되지 않은 공간은 유지한다.
- WRITE=0이면 두 공간의 저장값을 모두 유지한다.
- Q1Q0은 현재 ADDR이 선택한 공간을 읽은 값이다. 별도의 읽기 요청 입력은 없다.
- 채점은 쓰기 이후이므로, WRITE=1인 tick에는 방금 기록한 새 값이 출력된다.
- WRITE 버튼이 tick 뒤 자동으로 0이 되어도 현재 ADDR의 출력은 유지한다. D0/D1과 ADDR은 해제되지 않는다.
- WRITE=0에서 ADDR을 0 또는 1로 바꾸는 것만으로, 새 tick 없이 즉시 해당 저장 공간을 읽는다. 읽기는 저장 내용을 바꾸지 않으며 초기 상태와 쓰기 직후를 포함한 모든 도달 상태에서 양방향으로 반복할 수 있다.
- RESET 입력은 없다.
