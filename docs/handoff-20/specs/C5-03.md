# 13. 한 번 되돌리기

**선택한 판:** `C5-03-noreset` · RESET만 제거. 원본의 나머지 입력·출력·핵심 동작 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `D0,D1` | 저장할 값 |
| 입력 | `SAVE` | 저장 |
| 입력 | `UNDO` | 한 단계 되돌리기 |
| 출력 | `Q0,Q1` | 현재 값 |
| 출력 | `UNDO_AVAILABLE` | 되돌릴 수 있으면 1 |

**초기 상태:** 현재 값 00, 백업 값 00, UNDO_AVAILABLE=0.

**동작 규칙**

- SAVE=1이면 기존 현재 값을 백업하고, D1D0을 새 현재 값으로 저장하며 UNDO_AVAILABLE=1로 만든다.
- SAVE를 반복하면 가장 최근 SAVE 직전 값 하나만 백업으로 남는다.
- SAVE=0이고 UNDO=1이며 UNDO_AVAILABLE=1이면 백업 값을 현재 값으로 복구하고 UNDO_AVAILABLE=0으로 만든다.
- UNDO_AVAILABLE=0에서의 UNDO는 무시한다. 다음 SAVE 전까지 두 번째 UNDO는 효과가 없다.
- SAVE=UNDO=1이면 SAVE가 우선한다.
- 아무 요청도 없으면 현재 값과 되돌리기 가능 상태를 유지한다.
- 같은 값을 다시 SAVE해도 저장 요청으로 처리하므로 UNDO_AVAILABLE=1이 된다.
- Q1Q0은 처리 후 현재 값이며 RESET 입력은 없다.

**예시:** 초기 0 → SAVE 1 → SAVE 3 → UNDO → UNDO의 현재 값은 차례로 0,1,3,1,1이다. 마지막 두 UNDO 중 첫 번째만 성공한다.
