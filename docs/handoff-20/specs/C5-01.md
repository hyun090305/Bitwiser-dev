# 11. 누적 계산기

**선택한 판:** `C5-01` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `D0,D1` | 더할 값 |
| 입력 | `ADD` | 덧셈 요청 |
| 입력 | `RESET` | 초기화 |
| 출력 | `Q0,Q1` | 이번 tick 이후 누적값 |

**초기 상태:** Q1Q0=00.

**동작 규칙**

- D=2×D1+D0으로 해석한다.
- RESET=1이면 ADD와 관계없이 누적값을 0으로 만든다.
- RESET=0이고 ADD=1이면 기존 누적값에 D를 더하고 결과를 mod 4로 저장한다.
- RESET=0이고 ADD=0이면 누적값을 유지한다.
- Q1Q0은 해당 tick의 처리가 끝난 누적값이다.

**예시:** 누적값이 3일 때 ADD=1, D=2이면 새 값은 1이다.
