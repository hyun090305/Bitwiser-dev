# 6. 양방향 카운터

**선택한 판:** `C4-06` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `INC` | 증가(버튼) |
| 입력 | `DEC` | 감소(버튼) |
| 입력 | `RESET` | 0으로 초기화(버튼) |
| 출력 | `BIT0` | 현재 값의 하위 비트 |
| 출력 | `BIT1` | 현재 값의 상위 비트 |

**초기 상태:** BIT1BIT0=00.

**동작 규칙**

- RESET=1이면 다른 입력과 관계없이 값을 0으로 만든다.
- RESET=0이고 INC=1, DEC=0이면 1 증가시킨다.
- RESET=0이고 INC=0, DEC=1이면 1 감소시킨다.
- INC와 DEC가 둘 다 0이거나 둘 다 1이면 값을 유지한다.
- 값은 0~3을 순환한다. 3에서 증가하면 0, 0에서 감소하면 3이다.
- BIT1BIT0은 처리를 마친 값을 나타낸다.
