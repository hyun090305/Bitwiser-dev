# 6. 양방향 카운터 / Up/Down Counter

2026-09-26 · [Issue #488](https://github.com/hyun090305/Bitwiser-dev/issues/488).
ID 32, 슬롯 C4-06. 현재 reference는 `memory20:up-down-counter-no-reset`.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| Button | INC, DEC | 증가, 감소 요청 |
| 출력 | BIT0, BIT1 | 값 = 2 × BIT1 + BIT0 |

처음 값은 0이다. INC만 누른 실제 tick에는 1 증가, DEC만 누른 tick에는
1 감소한다. 3에서 증가하면 0, 0에서 감소하면 3이다. 둘 다 누르거나
둘 다 누르지 않으면 유지한다. 입력 변경만으로 값이 바뀌지 않는다.
완료 tick에는 INC/DEC를 자동 해제하며, 해제는 추가 tick이 아니다.

예시 입력 `(INC, DEC)`:
`10,10,10,10,01,11,00,01,01,01` → 값 `1,2,3,0,3,3,3,2,1,0`.

현재 RESET 포트는 없다. 이전 `memory20:C4-06`은 RESET 우선 규칙 그대로
보존한다. 이전 compact 및 큰 고정 IO 정의는 `levelPreviousLayouts[32]`,
기존 compact 해답은 `tests/fixtures/legacy-memory/32-compact.json`에 있다.

기준 회로는 두 D+EN의 비트 반전 조건을 사용하며 19×25 보드를 유지한다.
논리 26블록, JUNCTION 포함 31블록이다. 최적 비용을 주장하지 않는다.
