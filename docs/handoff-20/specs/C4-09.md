# 9. ABBA 잠금장치

**선택한 판:** `C4-09-planar-core` · A/B 두 버튼 → SIGNAL+SUBMIT. 대기와 열린 상태 유지는 보존. 최근 네 글자를 검사하도록 변경하고 RESET 제거.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `SIGNAL` | 입력 글자: A=1, B=0 |
| 입력 | `SUBMIT` | 현재 글자를 제출하는 버튼 |
| 출력 | `UNLOCKED` | ABBA를 한 번이라도 입력했으면1, 아직 없으면0 |

**초기 상태:** UNLOCKED=0. 제출한 글자 이력은 비어 있다.

**동작 규칙**

- SIGNAL=1은 A, SIGNAL=0은 B를 뜻한다.
- SUBMIT=1인 tick에만 현재 SIGNAL에 해당하는 글자 하나를 제출한다.
- SUBMIT=0이면 SIGNAL을 무시하고 잠금 상태와 입력 이력을 유지한다.
- 제출된 가장 최근 네 글자가 A,B,B,A이면 네 번째 글자를 제출한 tick부터 UNLOCKED=1이다.
- 글자를 아직 네 개 제출하지 않았다면 열리지 않는다.
- 잘못된 글자가 있어도 최근 네 글자를 계속 검사한다. 겹친 패턴도 인정한다.
- 한 번 UNLOCKED=1이 되면 이후 입력과 관계없이 열린 상태를 유지한다.
- RESET 입력은 없다. 실행을 다시 시작하면 초기 상태로 돌아간다.

**예시:** 제출한 글자가 `A,A,B,B,A`이면 마지막 네 글자가 ABBA이므로 다섯 번째 제출에서 열린다. 제출 사이에 SUBMIT=0인 tick이 있어도 결과는 같다.
