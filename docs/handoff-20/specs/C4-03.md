# 3. 고장 기록등

**선택한 판:** `C4-03` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `FAULT` | 현재 고장 신호(스위치) |
| 입력 | `ACK` | 확인 및 해제 요청(버튼) |
| 출력 | `ALARM` | 미확인 고장 기록 |

**초기 상태:** ALARM=0.

**동작 규칙**

- FAULT=1이면 ALARM=1로 만든다.
- FAULT=0이고 ACK=1이면 ALARM=0으로 만든다.
- FAULT=ACK=0이면 ALARM을 유지한다.
- FAULT=ACK=1이면 FAULT가 우선하여 ALARM=1이다.
