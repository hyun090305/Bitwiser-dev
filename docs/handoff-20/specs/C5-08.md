# 18. 먼저 넣은 것부터 — Queue

**선택한 판:** `C5-08-status-full` · RESET만 제거. 원본의 나머지 입력·출력·핵심 동작 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `DATA` | 넣을 비트 |
| 입력 | `PUSH` | 삽입 요청 |
| 입력 | `POP` | 제거 요청 |
| 출력 | `DATA_OUT` | 마지막으로 꺼낸 데이터 |
| 출력 | `VALID` | 이번 POP 성공 |
| 출력 | `EMPTY` | 처리 후 빈 상태 |
| 출력 | `FULL` | 처리 후 가득 참 |

**초기 상태:** 항목 수 0, DATA_OUT=0, VALID=0, EMPTY=1, FULL=0.

**동작 규칙**

- 1비트 항목을 최대 두 개 저장한다. 데이터 0도 정상 항목 하나로 센다.
- 성공한 POP은 가장 먼저 넣은 항목을 꺼내 DATA_OUT에 기록하고 VALID=1로 만든다.
- POP이 없거나 실패하면 DATA_OUT을 유지하고 VALID=0으로 만든다.
- PUSH는 빈 공간이 있으면 DATA를 대기열의 끝에 넣는다.
- PUSH와 POP이 동시에 1이면 tick 시작 시 기존 항목을 먼저 POP한 다음 새 DATA를 PUSH한다.
- 빈 상태에서 POP은 실패한다. 빈 상태에서 동시 PUSH·POP이면 DATA만 저장하고 VALID=0이다.
- 가득 찬 상태에서 POP 없이 PUSH하면 무시한다. 가득 찬 상태의 동시 PUSH·POP은 둘 다 처리한다.
- EMPTY는 처리 후 항목 수가 0일 때만 1, FULL은 처리 후 항목 수가 2일 때만 1이다.
- RESET 입력은 없다.

**예시:** PUSH 0 → PUSH 1 → POP → POP에서는 DATA_OUT이 마지막 두 tick에 0,1로 나온다.

PUSH=POP=1인 경우의 점유·성공 결과:

| tick 시작 항목 수 | POP | PUSH | 처리 후 항목 수 | VALID | EMPTY | FULL |
|---:|---|---|---:|---:|---:|---:|
| 0 | 실패 | 성공 | 1 | 0 | 0 | 0 |
| 1 | 성공 | 성공 | 1 | 1 | 0 | 0 |
| 2 | 성공 | 성공 | 2 | 1 | 0 | 1 |

DATA_OUT은 현재 맨 위/맨 앞 항목을 미리 보여주는 출력이 아니라, 마지막으로 성공한 POP에서 꺼낸 값이다.
