# 19. 수신 대기 우편함

**선택한 판:** `C5-09-noreset` · RESET만 제거. 원본의 나머지 입력·출력·핵심 동작 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `DATA` | 보낼 비트 |
| 입력 | `SEND` | 보내기 요청 |
| 입력 | `TAKE` | 수신 요청 |
| 출력 | `FULL` | 처리 후 항목 있음 |
| 출력 | `DATA_OUT` | 마지막으로 전달한 값 |
| 출력 | `VALID` | 이번 TAKE 성공 |
| 출력 | `ACCEPTED` | 이번 SEND 성공 |

**초기 상태:** 우편함은 비어 있으며 FULL=DATA_OUT=VALID=ACCEPTED=0.

**동작 규칙**

- 1비트 항목 하나를 보관한다. 데이터 0도 정상 항목이다.
- SEND=1이고 빈 공간이 있으면 DATA를 저장하고 ACCEPTED=1로 만든다.
- TAKE=1이고 tick 시작 시 항목이 있으면 기존 항목을 꺼내 DATA_OUT에 기록하고 VALID=1로 만든다.
- 가득 찬 상태의 동시 SEND·TAKE는 기존 항목을 전달하고 새 DATA로 교체한다. VALID=ACCEPTED=1, FULL=1이다.
- 빈 상태의 동시 SEND·TAKE는 새 DATA를 저장만 한다. VALID=0, ACCEPTED=1, FULL=1이며 DATA_OUT은 유지한다.
- 가득 찬 상태에서 TAKE 없이 SEND하면 거절한다. 빈 상태에서 TAKE만 하면 실패한다.
- 실패한 TAKE 또는 TAKE가 없는 tick에는 DATA_OUT을 유지한다.
- VALID는 해당 tick의 TAKE 성공 여부, ACCEPTED는 SEND 성공 여부다. 성공하지 않은 tick에는 각각 0이다.
- FULL은 처리 후 항목이 있으면 1이며 RESET 입력은 없다.
