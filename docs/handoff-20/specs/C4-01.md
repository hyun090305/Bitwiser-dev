# 1. 저장 스위치

**선택한 판:** `C4-01` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `DATA` | 저장할 1비트 값(스위치) |
| 입력 | `LOAD` | 저장 요청(버튼) |
| 출력 | `VALUE` | 현재 저장된 값 |

**초기 상태:** VALUE=0.

**동작 규칙**

- LOAD=1이면 그 tick의 DATA를 저장한다.
- LOAD=0이면 저장값을 유지한다. 이때 DATA가 바뀌어도 저장값은 바뀌지 않는다.
- VALUE는 저장 처리를 마친 현재 값을 출력한다.
