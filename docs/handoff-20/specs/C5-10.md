# 20. 시간을 써서 나누기

**선택한 판:** `C5-10-divider-complete` · 기존 `C5-10` 문제 자리를 교체. 피제수 0~7, 제수 1~3, 몫·나머지·COMPLETE 출력. 발견한 평면해 45블록.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `A0,A1,A2` | 피제수 A, unsigned 3비트, 0~7 |
| 입력 | `B0,B1` | 제수 B, unsigned 2비트, 1~3 |
| 출력 | `Q0,Q1,Q2` | 몫 Q, unsigned 3비트 |
| 출력 | `R0,R1` | 나머지 R, unsigned 2비트 |
| 출력 | `COMPLETE` | 결과를 채점해도 되는 tick이면 1 |

**초기 상태:** 모든 D·D+EN의 저장 비트는 0. 한 테스트에 나눗셈 한 건을 처리한다. tick 0의 출력은 채점하지 않는다. 초기 조합 출력 Q·R을 모두 0으로 강제하지 않는다.

**플레이어에게 보여 줄 문제문**

피제수 A를 제수 B로 나눈 몫과 나머지를 구하세요. A는 0~7, B는 1~3이며 계산 중에는 입력이 바뀌지 않습니다. 결과가 준비되면 COMPLETE를 1로 켜세요. 실행 후 10 tick 안에 처음 COMPLETE가 켜지는 순간, Q가 몫이고 R이 나머지여야 합니다. 각 테스트는 메모리가 0인 상태에서 새로 시작합니다.

**동작·채점 규칙**

- A=4×A2+2×A1+A0, B=2×B1+B0으로 해석한다. B=0은 테스트 입력에 포함하지 않는다.
- 정답은 Q=⌊A/B⌋, R=A−B×Q이며 0≤R<B이다.
- 각 테스트 시작 전에 입력을 설정하고, 같은 A·B를 완료 또는 10 tick 제한까지 유지한다.
- 매 tick은 기존 상태로 DATA·EN 계산 → 모든 메모리 동시 갱신 → 같은 입력으로 출력 재계산 순서다.
- 그 뒤 t=1,2,…,10에서 COMPLETE를 확인한다. **처음 COMPLETE=1인 tick**에 Q·R을 즉시 비교하여 해당 테스트를 끝낸다.
- 첫 COMPLETE에서 결과가 틀리면 즉시 실패한다. 뒤에서 수정하더라도 통과시키지 않는다.
- 10번째 tick에 올바르게 완료하면 성공한다. 10 tick 동안 한 번도 COMPLETE=1이 아니면 실패한다.
- COMPLETE 이전의 Q·R과 완료 이후의 Q·R·COMPLETE에는 조건을 두지 않는다. 완료 유지·한 tick 펄스·다음 작업 접수 기능을 추가로 요구하지 않는다.
- START·RESET·BUSY 포트는 없다. 새 테스트의 실행 초기화가 다음 계산을 시작한다.
- D·D+EN 사용이나 내부 알고리즘 자체를 채점으로 강제하지 않는다. 시간 사용은 풀이 방법이며 외부 동작이 정답 기준이다.
- 24개 입력 조합을 모두 검사한다. 특별 채점의 완료 기한은 10이고, 첨부 해답의 실제 최대 8 tick과 구분한다.

| A | B | 정답 Q | 정답 R | 첨부 해답의 첫 COMPLETE tick |
|---:|---:|---:|---:|---:|
| 0 | 3 | 0 | 0 | 1 |
| 2 | 3 | 0 | 2 | 3 |
| 6 | 2 | 3 | 0 | 7 |
| 7 | 1 | 7 | 0 | 8 |
| 7 | 3 | 2 | 1 | 8 |

각 예시의 완료 tick은 첨부 회로에 대한 관측값이며 플레이어 해답을 그 tick으로 제한하는 조건이 아니다.
