# 5. 자동으로 닫히는 문

**선택한 판:** `C4-05` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `OPEN` | 열기 및 열림 시간 연장(버튼) |
| 출력 | `DOOR` | 열려 있으면 1 |

**초기 상태:** DOOR=0. 이전에 받은 OPEN 요청이 없다.

**동작 규칙**

- OPEN=1인 tick을 포함해 3 tick 동안 DOOR=1이다.
- 그동안 OPEN=1이 다시 들어오면 새 요청 tick부터 다시 3 tick 동안 열린다.
- 최근 3 tick에 OPEN=1이 한 번도 없으면 DOOR=0이다.
- OPEN을 매 tick 1로 입력하면 계속 열린다.
- tick 직후 OPEN 버튼이 자동으로 0이 되어도 그 tick의 DOOR 값은 유지한다. 해제는 추가 tick이 아니며 닫힘 시간을 앞당기지 않는다.

**예시:** OPEN이 `1,0,0,0`이면 DOOR는 `1,1,1,0`이다. OPEN이 `1,0,1,0,0,0`이면 DOOR는 `1,1,1,1,1,0`이다.
