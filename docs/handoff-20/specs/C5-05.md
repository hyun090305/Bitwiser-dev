# 15. 한 줄로 수신하기

**선택한 판:** `C5-05-status` · RESET만 제거. 원본의 나머지 입력·출력·핵심 동작 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `DATA` | 수신 비트 |
| 입력 | `RECEIVE` | 한 비트 수신 |
| 출력 | `Q0,Q1,Q2,Q3` | 가장 최근 완성된 4-bit 단어 |
| 출력 | `DONE` | 이번 tick에 단어 완성 |

**초기 상태:** 수신한 비트 수 0, Q3Q2Q1Q0=0000, DONE=0.

**동작 규칙**

- RECEIVE=1인 tick에만 DATA 한 비트를 받는다. RECEIVE=0에서는 수신 진행도를 유지한다.
- 한 단어는 4비트이며 MSB부터 받는다. 받은 순서가 a,b,c,d이면 완성값 Q3Q2Q1Q0은 abcd이다.
- 네 번째 비트를 받는 tick에 공개값 Q를 한꺼번에 갱신하고 DONE=1로 만든다.
- 그 밖의 tick에는 Q를 유지하고 DONE=0으로 만든다. RECEIVE=0인 tick도 DONE은 0이다.
- 한 단어를 완성하면 다음 RECEIVE부터 새 단어의 첫 비트를 받는다.
- 새 단어의 첫 세 비트를 받는 동안에는 이전에 완성된 단어를 계속 출력한다.
- RESET 입력은 없다.

**예시:** 수신 요청이 있는 tick의 DATA만 골라 `1,0,1,1`을 받으면 네 번째 수신에서 Q=1011, DONE=1이 된다.
