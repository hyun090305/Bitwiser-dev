# 14. 준비 후 한 번에 반영

**선택한 판:** `C5-04` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `D0,D1` | 준비할 값 |
| 입력 | `WRITE` | 준비 공간 쓰기 |
| 입력 | `COMMIT` | 공개 값 교체 |
| 입력 | `RESET` | 초기화 |
| 출력 | `Q0,Q1` | 공개 공간의 값 |

**초기 상태:** 준비 공간과 공개 공간이 모두 00.

**동작 규칙**

- RESET=1이면 다른 요청과 관계없이 준비 공간과 공개 공간을 모두 0으로 만든다.
- RESET=0이고 WRITE=1이면 D1D0을 준비 공간에 저장한다. WRITE만으로는 공개 출력이 바뀌지 않는다.
- RESET=0이고 COMMIT=1이면 tick 시작 시 준비 공간의 값을 공개 공간으로 복사한다.
- WRITE=COMMIT=1이면 기존 준비값을 공개하고, 새 D1D0은 준비 공간에 저장한다.
- COMMIT은 준비값을 복사할 뿐 준비 공간을 비우지 않는다. WRITE가 없다면 반복 COMMIT은 같은 값을 공개한다.
- Q1Q0은 공개 공간만 출력한다.

**예시:** 준비값이 1, 공개값이 0인 상태에서 WRITE=COMMIT=1, D=2를 넣으면 준비값은 2, 공개값은 1이 된다.
