# 2. 변화 감지기

**선택한 판:** `C4-02` · 원본 명세 유지.

| 구분 | 포트 | 의미 |
| --- | --- | --- |
| 입력 | `SIGNAL` | 변화를 감지할 스위치 입력 |
| 출력 | `RISE` | 상승 변화가 관측된 tick에만 1 |

**초기 상태:** RISE=0. 이전 tick의 SIGNAL은 0으로 간주한다.

**동작 규칙**

- 이전 tick의 SIGNAL=0이고 이번 tick의 SIGNAL=1일 때만 RISE=1이다.
- 0→0, 1→0, 1→1에서는 RISE=0이다.
- SIGNAL을 계속 1로 유지하면 처음 0→1로 바뀐 tick에만 반응한다.
- RISE는 이번 tick의 입력을 처리한 결과다. 첫 tick에 SIGNAL=1을 넣어도 RISE=1이다.

RISE는 저장된 tick 결과이므로 초기 상태의 SIGNAL 변경은 출력을 켜지 않는다. 상승 tick 뒤 SIGNAL을 다시 바꿔도 RISE는 다음 실제 tick까지 1을 유지한다.

**예시:** SIGNAL이 `0,1,1,0,1`이면 RISE는 `0,1,0,0,1`이다.
