# 메모리 20문제: 자유 입출력과 축소 격자

20개 모두 `fixIO: false`이며 빈 보드에서 시작합니다. INPUT/OUTPUT을 팔레트에서 놓고 자유롭게 옮길 수 있습니다. 기준 회로의 부품에도 고정 속성을 해제했습니다.

격자는 최소 6×6입니다. 기준 회로 바깥에 작은 문제는 한 칸, 나머지는 두 칸씩 여유를 남겼습니다. 아래 크기는 **행×열**입니다. 전체 격자 면적은 35,865칸에서 5,606칸으로 약 84% 줄었습니다.

배선의 불필요한 우회와 단순 연결용 분기점을 제거하고, 블록을 가까이 옮겨 다시 배선한 뒤 직각 구간을 압축했습니다. 여러 탐색 순서를 시도했으며 절대 최솟값을 증명한 배치는 아닙니다. 도선 교차·중복 점유·블록 충돌 없이 모든 기준 회로가 기존 채점을 통과합니다. 논리 부품과 동작 조건은 유지했습니다.

한국어·영어 문제 설명을 짧은 목표와 동작 규칙으로 다시 썼고, 한국어 힌트도 정리했습니다. 상세 엔진 계약은 원본 인계 문서에 남겨 두었습니다.

`npm run stages:compact`로 추가 배치 탐색과 데이터 생성을 할 수 있습니다. 기존 배치를 그대로 재생성하려면 `npm run stages:memory20`을 사용합니다. 실제 회로는 `tests/fixtures/memory20/{ID}.json`, 비용·격자 보고서는 [memory20-integration.json](memory20-integration.json)에 있습니다.

축소 전 보드 정의는 `levelPreviousLayouts`에 보관합니다. 기존 데모 백업의 큰 격자 회로를 잘라내지 않고 이전 설계로 보존하며, 현재 채점 버전으로 저장한 백업도 처리합니다. 현재 비용 기록과 구분하고, 내보내기·재가져오기에서 보존합니다.
